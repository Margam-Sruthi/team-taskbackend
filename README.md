# Team Task Manager - Backend

## Live API
https://team-taskbackend-production.up.railway.app

## Features
- User Authentication (JWT)
- Role-Based Access
- Project & Task APIs
- Secure REST APIs

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas

## Setup
1. Clone repo
2. Install dependencies:
   npm install
3. Add .env file:
   MONGO_URI=your_mongo_uri
   JWT_SECRET=your_secret
4. Run server:
   npm start
